# InnovaCode – Shared Farm Web Application

## 📌 Project Overview

**InnovaCode** is a Software Engineering project that proposes an intelligent **Shared Farm Web Application** designed to connect farmers, shareholders, customers, investors, delivery partners, administrators, and community members through a unified digital platform.

The system combines **farm management, e-commerce, shared farm ownership, investment opportunities, AI-powered features, logistics, education, and sustainability tracking**. Its main goal is to support sustainable farming while providing transparent farm management and convenient access to local organic products.

This repository contains the project's Software Engineering documentation, including the requirements, software design, and testing specifications.

---

## 🎯 Project Goals

The main goals of the Shared Farm System are to:

* Connect farm owners, customers, shareholders, and investors.
* Allow shareholders to manage their farm shares and claim entitled produce.
* Provide an online marketplace for local organic products.
* Support investment in sustainable farm projects.
* Provide dashboards, reports, and transparency tools.
* Integrate AI-based demand forecasting and recommendations.
* Support recipe suggestions and food-storage advice.
* Encourage sustainability and community awareness through educational content and events.

---

## 👥 User Roles

The system is designed to support multiple categories of users:

* **Shareholders** – Manage farm shares, view dashboards, claim produce, and participate in decision-making.
* **Customers** – Browse products, place orders, subscribe to produce boxes, and manage purchases.
* **Investors** – Explore farm projects, make investments, track returns, and redeem benefits.
* **Administrators** – Manage users, transactions, reports, and system operations.
* **Community Members** – Access educational content, blogs, tutorials, workshops, and farm events.
* **Delivery Partners** – Manage delivery activities and update delivery status.

## 🏗️ Software Engineering Design

The project follows a structured Software Engineering approach covering requirements, data design, architecture, component design, user interface design, behavioral modeling, and testing.

### Architecture

The system uses a **Layered Architecture Style** to separate different responsibilities and improve maintainability, scalability, and security.

The architecture contains four layers, including the:

* Presentation Layer
* Application Layer
* Data-related layer(s)
* Supporting system functionality

The Presentation Layer provides interfaces for different user roles, including customer, shareholder, investor, administrator, delivery partner, and community member.

## ⚠️ Limitations and Constraints

The project documentation identifies several challenges and limitations, including:

* User hesitation toward shared farm ownership.
* Compliance with UAE investment, food safety, and e-commerce regulations.
* Dependence on external services such as payment gateways and cloud services.
* Scalability challenges as the number of users and transactions increases.
* Dependence on the quality of data for AI predictions.
* Data privacy and security requirements.
* Possible connectivity limitations in rural areas.

Some proposed features, such as IoT integration and blockchain-based investment tracking, are identified as future possibilities rather than part of the current project scope.
